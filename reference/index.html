Part 1

1st Order ODE Methods

Six core techniques for solving first-order ODEs. Choose the method based on the form of the equation.

Method When to Use Key Idea
Separable ODE can be written as $g(y)\,dy = f(x)\,dx$ Separate variables, integrate both sides
Exact $M_y = N_x$ for $M\,dx + N\,dy = 0$ Find potential function $u(x,y) = c$
Integrating Factor Non-exact or linear 1st-order ODEs Multiply by $\mu(x) = e^{\int p(x)\,dx}$ to make exact
1st Order Linear $y' + p(x)y = r(x)$ $y = e^{-h}\!\int e^h\,r\,dx + C$, where $h = \int p\,dx$
Homogeneous Sub. ODE of the form $y' = f(y/x)$ Substitute $y = vx$; reduces to separable ODE
Bernoulli $y' + p(x)y = g(x)y^a$ Substitute $u = y^{1-a}$; reduces to linear ODE
Part 2

2nd Order Homogeneous ODEs

Methods for $y'' + ay' + by = 0$ and its variants. The characteristic equation drives all three cases.

Method When to Use Key Idea
Characteristic Eq. Constant-coefficient: $y'' + ay' + by = 0$ Try $y = e^{\lambda x}$; solve $\lambda^2 + a\lambda + b = 0$. Three cases: distinct real, repeated, complex roots
Reduction of Order One solution $y_1$ is already known Let $y_2 = u(x)\cdot y_1$; reduces to 1st-order ODE for $u'$
Euler–Cauchy $x^2 y'' + axy' + by = 0$ Try $y = x^m$; solve $m^2 + (a-1)m + b = 0$

Characteristic Root Cases

Root TypeRoots $\lambda$Basis of $y_h$
Distinct Real $\lambda_1 \neq \lambda_2$ (real) $e^{\lambda_1 x},\quad e^{\lambda_2 x}$
Repeated Real $\lambda_1 = \lambda_2 = \lambda$ $e^{\lambda x},\quad xe^{\lambda x}$
Complex $\lambda = \alpha \pm \beta i$ $e^{\alpha x}\cos\beta x,\quad e^{\alpha x}\sin\beta x$
Repeated Complex $\alpha \pm \beta i$ (double) $e^{\alpha x}\cos\beta x,\; xe^{\alpha x}\cos\beta x,\; e^{\alpha x}\sin\beta x,\; xe^{\alpha x}\sin\beta x$
Part 3

Non-Homogeneous ODEs

The general solution always splits into a homogeneous part and a particular part.

✦
General Solution Structure
$y = y_h + y_p$

Undetermined Coefficients — Guess Table

Select a trial $y_p$ based on the form of $r(x)$. If any trial term duplicates a term in $y_h$, apply the Modification Rule.

⚠
Modification Rule If a term in the trial $y_p$ already appears in $y_h$, multiply that term by $x$ (or $x^2$ if it corresponds to a double root).
Form of $r(x)$Trial $y_p$Notes
$ke^{\alpha x}$ $Ce^{\alpha x}$ Multiply by $x^s$ if $\alpha$ is a root of multiplicity $s$
$kx^n$ $K_n x^n + K_{n-1}x^{n-1} + \cdots + K_0$ Include all lower-degree terms even if absent in $r(x)$
$k\cos\beta x$ or $k\sin\beta x$ $K\cos\beta x + M\sin\beta x$ Always guess both, even if only one appears in $r(x)$
$ke^{\alpha x}\cos\beta x$ or $ke^{\alpha x}\sin\beta x$ $e^{\alpha x}(K\cos\beta x + M\sin\beta x)$ Multiply by $x$ if $\alpha \pm \beta i$ are characteristic roots
$kx^n e^{\alpha x}$ $e^{\alpha x}(K_n x^n + \cdots + K_0)$ Combine polynomial and exponential families
Sum of above families Sum of corresponding trial functions Sum Rule — apply Modification Rule to each family independently
Method
Variation of Parameters
Works for any $r(x)$ (no restriction on form). Given $y_h = C_1 y_1 + C_2 y_2$, the particular solution is:
$$y_p = -y_1 \int\frac{y_2\,r}{W}\,dx \;+\; y_2 \int\frac{y_1\,r}{W}\,dx$$

where $W = W(y_1, y_2) = y_1 y_2' - y_2 y_1'$ is the Wronskian.

Part 4 — Chapter 3

Higher-Order ODEs (nth Order)

Extensions of 2nd-order techniques to degree-$n$ constant-coefficient ODEs.

MethodDescription
Char. Equation Generalized to a degree-$n$ polynomial in $\lambda$. Handles distinct real, repeated real, simple complex, and repeated complex roots — apply same basis rules, extended to $n$ independent solutions.
Undetermined Coeff. Extended to nth-order constant-coefficient non-homogeneous ODEs. The same guess table applies; check each trial term against all $n$ homogeneous basis functions.
Variation of Params. Uses $n$ Wronskian sub-determinants $W_1, \ldots, W_n$: $$y_p = \sum_{k=1}^{n} y_k \int \frac{W_k}{W}\,r\,dx$$
Foundations

Key Concepts

Theoretical underpinnings required for understanding solution structure and validity.

Wronskian
$W(y_1, y_2) = y_1 y_2' - y_2 y_1'$
Tests linear independence of solutions. $W \neq 0$ on an interval guarantees $y_1, y_2$ form a fundamental set. Required for Variation of Parameters.
Superposition
Superposition Principle
Any linear combination of solutions to a homogeneous linear ODE is also a solution. This is what allows $y_h = C_1 y_1 + C_2 y_2$.
Existence & Uniqueness
Existence & Uniqueness Theorem
Guarantees a unique solution given continuous coefficients and initial conditions. Confirms that a solution exists before you attempt to find it.
