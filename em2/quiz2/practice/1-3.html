Part 1

1st Order ODEs

Problems 1–9 covering separable, exact, linear, homogeneous substitution, and Bernoulli equations.

1.1 Separable ODEs Separate & Integrate

1
Solve $y' = -2xy$, with $y(0) = 3$.
Solution
Separate variables: $$\frac{1}{y}\,dy = -2x\,dx$$
Integrate both sides: $\ln|y| = -x^2 + C_1$, so $y = Ce^{-x^2}$.
Apply $y(0) = 3$: $C = 3$.
Answer$y = 3e^{-x^2}$
2
Solve $\dfrac{dy}{dx} = \dfrac{x^2}{1 + y^2}$.
Solution
Separate: $(1+y^2)\,dy = x^2\,dx$.
Integrate both sides.
Answer$y + \dfrac{y^3}{3} = \dfrac{x^3}{3} + C$  (implicit)
3
Radioactive decay: $y' = ky$, $y(0) = y_0$. Find $y(t)$.
Solution
Separate: $\dfrac{dy}{y} = k\,dt \implies \ln|y| = kt + C_1$.
For decay $k < 0$. Given half-life $H$: $k = -\ln(2)/H$.
Answer$y(t) = y_0 e^{kt}$

1.2 Exact ODEs Potential Function

4
Check exactness and solve: $(2xy+1)\,dx + (x^2+3y^2)\,dy = 0$.
Solution
$M = 2xy+1$, $N = x^2+3y^2$. Check: $M_y = 2x = N_x$ — Exact.
Integrate $u_x = M$: $u = x^2y + x + f(y)$.
Apply $u_y = N$: $x^2 + f'(y) = x^2 + 3y^2 \implies f(y) = y^3$.
Answer$x^2y + x + y^3 = C$
5
Solve $(3x^2+y)\,dx + (x-2y)\,dy = 0$.
Solution
$M_y = 1 = N_x$ — Exact.
$u = \int(3x^2+y)\,dx = x^3 + xy + f(y)$.
$u_y = x + f'(y) = x - 2y \implies f(y) = -y^2$.
Answer$x^3 + xy - y^2 = C$

1.3 Integrating Factor & Linear ODEs $\mu = e^{\int p\,dx}$

6
Solve $y' + \tfrac{1}{x}y = x$, $y(1) = 2$. IVP
Solution
Integrating factor: $\mu = e^{\int (1/x)\,dx} = x$.
Multiply: $(xy)' = x^2 \implies xy = \tfrac{x^3}{3} + C$.
Apply $y(1)=2$: $2 = \tfrac{1}{3} + C \implies C = \tfrac{5}{3}$.
Answer$y = \dfrac{x^2}{3} + \dfrac{5}{3x}$
7
Solve $y' - 2y = e^{3x}$.
Solution
Integrating factor: $\mu = e^{-2x}$.
$(e^{-2x}y)' = e^x \implies e^{-2x}y = e^x + C$.
Answer$y = e^{3x} + Ce^{2x}$

1.4 Homogeneous Substitution $y = vx$

8
Solve $y' = \dfrac{y^2 - x^2}{2xy}$.
Solution
Rewrite as $y' = \dfrac{(y/x)^2 - 1}{2(y/x)}$. Let $v = y/x$, so $y' = v + xv'$.
$$xv' = \frac{v^2-1}{2v} - v = \frac{-v^2-1}{2v}$$
Separate: $\dfrac{2v}{v^2+1}\,dv = -\dfrac{dx}{x}$ $\implies \ln(v^2+1) = -\ln|x|+C_1$.
Re-substitute $v = y/x$.
Answer$x^2 + y^2 = Kx$

1.5 Bernoulli Equation $u = y^{1-a}$

9
Solve $y' - y = -y^2$.
Solution
$a=2$. Let $u = y^{-1}$, divide ODE by $y^2$: $-u' - u = -1 \implies u' + u = 1$.
Linear ODE. Integrating factor $e^x$: $(e^x u)' = e^x \implies u = 1 + Ce^{-x}$.
Re-substitute $u = 1/y$.
Answer$y = \dfrac{1}{1 + Ce^{-x}}$
Part 2

2nd Order Homogeneous ODEs

Problems 10–16. Characteristic equation, reduction of order, and Euler–Cauchy equations.

2.1 Distinct Real Roots

10
Solve $y'' - 5y' + 6y = 0$.
Solution
Char. eq.: $\lambda^2 - 5\lambda + 6 = (\lambda-2)(\lambda-3) = 0 \implies \lambda = 2, 3$.
Answer$y = C_1 e^{2x} + C_2 e^{3x}$
11
Solve $y'' + y' - 2y = 0$, $y(0)=4$, $y'(0)=-5$. IVP
Solution
$\lambda^2+\lambda-2 = (\lambda+2)(\lambda-1) = 0 \implies \lambda = 1, -2$.
$y = C_1 e^x + C_2 e^{-2x}$. ICs: $C_1+C_2=4$, $C_1-2C_2=-5$. Solve: $C_1=1$, $C_2=3$.
Answer$y = e^x + 3e^{-2x}$

2.2 Repeated Real Root

12
Solve $y'' + 6y' + 9y = 0$.
Solution
$(\lambda+3)^2 = 0 \implies \lambda = -3$ (double root).
Answer$y = (C_1 + C_2 x)e^{-3x}$

2.3 Complex Roots

13
Solve $y'' + 4y' + 13y = 0$.
Solution
$\lambda = \dfrac{-4 \pm \sqrt{16-52}}{2} = -2 \pm 3i$.
Answer$y = e^{-2x}(C_1\cos 3x + C_2\sin 3x)$

2.4 Reduction of Order $y_2 = u(x)\,y_1$

14
$y_1 = e^x$ solves $y'' - 2y' + y = 0$. Find the general solution.
Solution
Let $y_2 = u(x)e^x$. Substituting: $u'' = 0 \implies u = C_1 x + C_2$.
Choose $C_1=1, C_2=0$: $y_2 = xe^x$.
Answer$y = (C_1 + C_2 x)e^x$

2.5 Euler–Cauchy Equation $y = x^m$

15
Solve $x^2 y'' - 3xy' + 4y = 0$.
Solution
Try $y = x^m$: $m(m-1) - 3m + 4 = m^2 - 4m + 4 = (m-2)^2 = 0 \implies m = 2$ (double).
Answer$y = x^2(C_1 + C_2\ln x)$
16
Solve $x^2 y'' + xy' - 4y = 0$.
Solution
Indicial equation: $m^2 - 4 = 0 \implies m = \pm 2$.
Answer$y = C_1 x^2 + C_2 x^{-2}$
Part 3

2nd Order Non-Homogeneous ODEs

Problems 17–22. General solution: $y = y_h + y_p$.

3.1 Method of Undetermined Coefficients Guess & Match

17
Solve $y'' + 3y' + 2y = 6e^{3x}$. Basic Rule
Solution
$y_h$: $\lambda^2+3\lambda+2=0 \implies \lambda=-1,-2$. So $y_h = C_1 e^{-x}+C_2 e^{-2x}$.
Try $y_p = Ae^{3x}$: $9A+9A+2A = 6 \implies 20A=6 \implies A = \tfrac{3}{10}$.
Answer$y = C_1 e^{-x} + C_2 e^{-2x} + \tfrac{3}{10}e^{3x}$
18
Solve $y'' + 3y' + 2y = e^{-x}$. Modification Rule
Solution
$y_h = C_1 e^{-x}+C_2 e^{-2x}$. Since $e^{-x} \in y_h$, try $y_p = Axe^{-x}$ (Modification Rule).
$y_p' = A(1-x)e^{-x}$, $y_p'' = A(x-2)e^{-x}$. Substituting: $A(x-2)+3A(1-x)+2Ax = 1 \implies A=1$.
Answer$y = C_1 e^{-x} + C_2 e^{-2x} + xe^{-x}$
19
Solve $y'' - y = x^2$.
Solution
$y_h = C_1 e^x + C_2 e^{-x}$. Try $y_p = Ax^2+Bx+C$.
$2A-(Ax^2+Bx+C) = x^2 \implies A=-1,\ B=0,\ C=-2$.
Answer$y = C_1 e^x + C_2 e^{-x} - x^2 - 2$
20
Solve $y'' + y = 2x + \cos x$. Sum Rule
Solution
$y_h = C_1\cos x + C_2\sin x$.
For $r_1 = 2x$: try $y_{p1} = Ax+B \implies A=2, B=0$.
For $r_2 = \cos x$: $\cos x \in y_h$, so try $y_{p2} = x(C\cos x + D\sin x)$. Substituting gives $D=\tfrac{1}{2}$, $C=0$.
Answer$y = C_1\cos x + C_2\sin x + 2x + \tfrac{x}{2}\sin x$

3.2 Variation of Parameters Wronskian Integrals

21
Solve $y'' + y = \sec x$.
Solution
$y_1 = \cos x$, $y_2 = \sin x$. Wronskian: $W = 1$.
$u' = -\sin x\sec x = -\tan x \implies u = \ln|\cos x|$.
$v' = \cos x\sec x = 1 \implies v = x$.
$y_p = \cos x\ln|\cos x| + x\sin x$.
Answer$y = C_1\cos x + C_2\sin x + \cos x\ln|\cos x| + x\sin x$
22
Solve $y'' - 2y' + y = \dfrac{e^x}{x^2}$, $x > 0$.
Solution
$y_1 = e^x$, $y_2 = xe^x$. $W = e^{2x}$.
$u' = -\dfrac{xe^x \cdot e^x/x^2}{e^{2x}} = -\dfrac{1}{x} \implies u = -\ln x$.
$v' = \dfrac{1}{x^2} \implies v = -\dfrac{1}{x}$.
$y_p = -e^x\ln x - e^x$ (the $-e^x$ absorbs into $C_1 e^x$).
Answer$y = (C_1 + C_2 x)e^x - e^x\ln x$
Part 4

Higher-Order ODEs (Ch. 3)

Problems 23–27. nth-order extensions of characteristic equation, undetermined coefficients, and variation of parameters.

4.1 Characteristic Equation (nth Order)

23
Solve $y''' - 6y'' + 11y' - 6y = 0$.
Solution
$\lambda^3-6\lambda^2+11\lambda-6 = (\lambda-1)(\lambda-2)(\lambda-3) = 0$.
Answer$y = C_1 e^x + C_2 e^{2x} + C_3 e^{3x}$
24
Solve $y^{(4)} - y = 0$.
Solution
$\lambda^4-1 = (\lambda^2-1)(\lambda^2+1) = 0 \implies \lambda = 1, -1, i, -i$.
Answer$y = C_1 e^x + C_2 e^{-x} + C_3\cos x + C_4\sin x$
25
Solve $y^{(4)} + 2y'' + y = 0$ (repeated complex roots).
Solution
$(\lambda^2+1)^2 = 0 \implies \lambda = \pm i$ (each a double root).
Answer$y = (C_1 + C_2 x)\cos x + (C_3 + C_4 x)\sin x$

4.2 Undetermined Coefficients (nth Order)

26
Solve $y''' - y'' = 3e^x - 1$.
Solution
$\lambda^2(\lambda-1)=0 \implies \lambda=0,0,1$. So $y_h = C_1+C_2 x+C_3 e^x$.
For $r=-1$: $\lambda=0$ is double root → try $y_{p1}=Ax^2$. Get $-2A=-1 \implies A=\tfrac{1}{2}$.
For $r=3e^x$: $\lambda=1$ is root → try $y_{p2}=Bxe^x$. Get $B=3$.
Answer$y = C_1 + C_2 x + C_3 e^x + \tfrac{x^2}{2} + 3xe^x$

4.3 Variation of Parameters (nth Order)

27
Solve $y''' - y'' - y' + y = 6e^{2x}$ using variation of parameters.
Solution
$(\lambda-1)^2(\lambda+1)=0 \implies \lambda=1,1,-1$. Basis: $y_1=e^x$, $y_2=xe^x$, $y_3=e^{-x}$.
$W(y_1,y_2,y_3) = -4e^x$. Compute sub-Wronskians $W_1, W_2, W_3$ and integrate $y_p = \sum y_k \int (W_k/W)\,r\,dx$.
Answer$y = (C_1 + C_2 x)e^x + C_3 e^{-x} + e^{2x}$
