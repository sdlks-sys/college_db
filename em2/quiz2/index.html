3.1

Homogeneous Linear Constant-Coefficient ODE

The homogeneous $n$th-order ODE with real constant coefficients $a_1, \ldots, a_n$:

$$y^{(n)} + a_1 y^{(n-1)} + a_2 y^{(n-2)} + \cdots + a_{n-1} y' + a_n y = 0$$
Linear Independence — Wronskian Test. Solutions $y_1,\ldots,y_n$ are linearly independent on $[a,b]$ if and only if their Wronskian is nonzero: $$W(y_1,\ldots,y_n) = \det\begin{pmatrix} y_1 & y_2 & \cdots & y_n \\ y_1' & y_2' & \cdots & y_n' \\ \vdots & & & \vdots \\ y_1^{(n-1)} & y_2^{(n-1)} & \cdots & y_n^{(n-1)}\end{pmatrix} \neq 0$$ Then the general complementary solution is $y_c = c_1 y_1 + c_2 y_2 + \cdots + c_n y_n$.

Characteristic Equation

Substituting $y = Ce^{\lambda x}$ yields the characteristic (indicial) equation:

$$\lambda^n + a_1\lambda^{n-1} + a_2\lambda^{n-2} + \cdots + a_{n-1}\lambda + a_n = 0$$

Rules for Constructing $y_c$

1

Single Real Root $\lambda = \alpha$

Contributes one solution term.

Contribution
$A e^{\alpha x}$
2

Repeated Real Root $\lambda = \alpha$ ($r$ times)

Contributes $r$ linearly independent solutions.

Contribution
$e^{\alpha x},\; xe^{\alpha x},\; x^2 e^{\alpha x},\;\ldots,\; x^{r-1}e^{\alpha x}$
3

Complex Conjugate Pair $\lambda = \alpha \pm i\beta$

Single occurrence: contributes two real solutions.

Contribution
$e^{\alpha x}\cos\beta x,\;\; e^{\alpha x}\sin\beta x$
4

Complex Pair $\lambda = \alpha \pm i\beta$ Repeated $s$ Times

Contributes $2s$ linearly independent solutions.

Contribution (each $k = 0,\ldots,s-1$)
$x^k e^{\alpha x}\cos\beta x,\;\; x^k e^{\alpha x}\sin\beta x$
Rule 5 (Assembly). The general solution $y_c$ is an arbitrary linear combination of all terms produced by Rules 1–4. The number of arbitrary constants always equals the degree $n$ of the characteristic polynomial.

3.2

Method of Undetermined Coefficients (Finding $y_p$)

For the non-homogeneous ODE $y^{(n)} + a_1 y^{(n-1)} + \cdots + a_n y = f(x)$, guess the form of $y_p$ from $f(x)$, then determine the coefficients by substitution.

$x^m$ (lowest deriv. is order $s$) $x^s(A_0 x^m + \cdots + A_m)$ $\lambda=0$ is root of order $s$
$Pe^{ax}$ $Be^{ax}$ $e^{ax} \notin y_c$

Method Limitation. Undetermined coefficients works only when $f(x)$ is of the above recognisable types (exponentials, polynomials, sines/cosines and their products). For general $f(x)$, use Variation of Parameters (§3.4).
3.3

Cauchy-Euler Equation

Variable-coefficient ODE where coefficients are powers of $x$:

$$x^2 y'' + Axy' + By = 0, \qquad x > 0$$
Solution Ansatz. Try $y(x) = x^m$. Substituting gives the indicial equation: $$m(m-1) + Am + B = 0 \quad\Longrightarrow\quad m^2 + (A-1)m + B = 0$$ Solve for $m$ using the quadratic formula. Three cases follow:
Case 1
Two distinct real roots $m = \alpha,\,\beta$
$$y_c = C_1 x^\alpha + C_2 x^\beta$$
Case 2
Repeated real root $m = \mu$ (double)
$$y_c = C_1 x^\mu + C_2 x^\mu\ln x$$
Case 3
Complex conjugate roots $m = \alpha \pm i\beta$
$$y_c = C_1 x^\alpha\cos(\beta\ln x) + C_2 x^\alpha\sin(\beta\ln x)$$

Alternative: Transform to Constant-Coefficient ODE

Substitution $t = \ln x$ (i.e., $x = e^t$) converts the Cauchy-Euler equation to a constant-coefficient ODE. This approach is often faster for higher-order Cauchy-Euler equations.
1
Let $t = \ln x$, so $x = e^t$. Define $Y(t) = y(e^t)$.
2
Chain rule gives: $xy' = Y'(t)$ and $x^2 y'' = Y''(t) - Y'(t)$.
3
Substitute to obtain: $Y'' + (A-1)Y' + BY = 0$ — a constant-coefficient ODE.
4
Solve $Y(t)$ using §3.1 methods, then substitute back $t = \ln x$ to get $y(x) = Y(\ln x)$.
For $x < 0$: replace $x$ with $|x|$ and let $t = \ln|x|$.
3.4

Variation of Parameters & Green's Function

Applies to any linear non-homogeneous ODE regardless of whether $f(x)$ is of a recognisable type. Introduced by Euler, completed by Lagrange.

$$y'' + p(x)y' + q(x)y = f(x), \qquad \text{with } y_c = c_1 y_1 + c_2 y_2$$

Process (2nd Order)

1
Find $y_c$. Solve the homogeneous equation to get two linearly independent solutions $y_1$, $y_2$.
2
Compute the Wronskian: $W = \begin{vmatrix} y_1 & y_2 \\ y_1' & y_2' \end{vmatrix} = y_1 y_2' - y_2 y_1'$
3
Assert $y_p = u(x)y_1 + v(x)y_2$ and impose $u'y_1 + v'y_2 = 0$ to obtain: $$u' = \frac{-y_2 f}{W}, \qquad v' = \frac{y_1 f}{W}$$
4
Integrate $u'$ and $v'$ to get $u(x)$ and $v(x)$, then assemble $y_p = uy_1 + vy_2$.

Higher-Order Generalisation ($n$th order)

For $y^{(n)} + p_{n-1}y^{(n-1)} + \cdots + p_0 y = r(x)$ with basis $\{y_1,\ldots,y_n\}$: $$y_p = \sum_{k=1}^n y_k \int \frac{W_k(x)}{W(x)}\,r(x)\,dx$$ where $W_j$ is obtained from the Wronskian $W$ by replacing its $j$th column with $(0,0,\ldots,0,1)^T$.

Green's Function (BVP)

For the boundary value problem $y'' + a(x)y' + b(x)y = f(x)$ on $[a,b]$ with homogeneous BCs, the particular solution is expressed as an integral operator:

$$y_p(x) = \int_a^b G(x,t)\,f(t)\,dt$$

where the Green's function is defined piecewise:

$$G(x,t) = \begin{cases} \dfrac{y_1(t)\,y_2(x)}{W(t)}, & a \le t \le x \\[8pt] \dfrac{y_1(x)\,y_2(t)}{W(t)}, & x \le t \le b \end{cases}$$

Properties of the Green's Function

①

Satisfies homogeneous DE

$G(x,t)$ satisfies the homogeneous equation in $a \le x < t$ and $t < x \le b$ separately.

②

Continuity of $G$

$G(x,t)$ is a continuous function of $x$ across the entire interval $[a,b]$.

③

Satisfies homogeneous BCs

$G(x,t)$ satisfies the same homogeneous boundary conditions as imposed on $y$.

④

Jump discontinuity in $G_x$

The derivative $G_x(x,t)$ is discontinuous across $x = t$ with:

Jump condition
$G_x(x,x^+) - G_x(x,x^-) = -1$
IVP Integral Form (Leibniz). The solution of $y'' + a(x)y' + b(x)y = f(x)$ with $y(a) = y'(a) = 0$ is: $$y(x) = \int_a^x \frac{y_1(t)y_2(x) - y_1(x)y_2(t)}{W(t)}\,f(t)\,dt$$ Differentiation via Leibniz's rule confirms the ICs are satisfied automatically.
3.5

Reduction of Order (Finding $y_2$ from $y_1$)

Given one known solution $y_1(x)$ of the homogeneous equation, a second linearly independent solution $y_2$ can be found by the ansatz $y_2 = u(x)y_1(x)$.

$$y'' + p(x)y' + q(x)y = 0, \qquad y_1 \text{ is known}$$
Key Formula. $$u(x) = \int \frac{e^{-\int p(x)\,dx}}{y_1^2(x)}\,dx \qquad\Longrightarrow\qquad y_2 = u(x)\,y_1(x)$$ The general solution is then $y = c_1 y_1 + c_2 y_2 = c_1 y_1 + c_2\,u(x)y_1$.

Derivation Steps

1
Set $y_2 = u(x)y_1$. Differentiate: $y_2' = u'y_1 + uy_1'$, $\quad y_2'' = u''y_1 + 2u'y_1' + uy_1''$
2
Substitute into the DE. Since $y_1$ solves the homogeneous equation, the $u$ terms cancel, leaving: $$y_1 u'' + 2(y_1' + py_1)u' = 0 \qquad \text{(no }u\text{ term)}$$
3
Reduce order. Let $v = u'$: the equation $y_1 v' + 2(y_1' + py_1)v = 0$ is separable. Solving gives: $$v = u' = \frac{C}{y_1^2}\,e^{-\int p\,dx}$$
4
Integrate. $u = \int v\,dx$, then $y_2 = u\,y_1$.

Worked Example

Example. Solve $y'' + 6y' + 9y = 0$ given $y_1 = e^{-3x}$.

Here $p(x) = 6$, so $e^{-\int 6\,dx} = e^{-6x}$ and $y_1^2 = e^{-6x}$.

$u = \displaystyle\int \frac{e^{-6x}}{e^{-6x}}\,dx = \int 1\,dx = x$ (ignoring the constant).

Therefore $y_2 = x\,e^{-3x}$, and the general solution is: $$y = c_1 e^{-3x} + c_2\,x e^{-3x} = (c_1 + c_2 x)e^{-3x}$$ This matches the repeated-root Rule 2 result with characteristic root $\lambda = -3$ (double).
