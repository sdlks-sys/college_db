Finding the Particular Solution $y_p$

For any non-homogeneous linear ODE, the general solution splits into two parts. This guide covers how to determine the correct trial function (guess) for $y_p$ depending on the form of the forcing function $r(x)$, plus when and how to modify your guess.

General Solution Structure
$y = y_h + y_p$
where $y_h = c_1 y_1 + c_2 y_2$ solves the homogeneous ODE, and $y_p$ is any particular solution.

The Three Choice Rules

Before substituting your guess, verify it against these rules in order.

①

Basic Rule

If $r(x)$ belongs to a family in the table above, choose $y_p$ from the same row. Substitute $y_p$ and its derivatives into the ODE to solve for the unknown coefficients.

Example
$r(x) = 3x^2$ → try $y_p = Ax^2 + Bx + C$
②

Modification Rule

If any term in your trial $y_p$ is already a solution of the homogeneous ODE $y_h$, multiply the entire trial function by $x$. If it still overlaps, multiply by $x^2$ (for a double root).

Example
$r(x) = e^{-x}$, but $e^{-x} \in y_h$ → try $y_p = Axe^{-x}$
③

Sum Rule

If $r(x) = r_1(x) + r_2(x) + \cdots$, compute a separate trial function for each part individually, then add them together: $y_p = y_{p_1} + y_{p_2} + \cdots$

Example
$r(x) = e^{2x} + \sin x$ → $y_p = Ae^{2x} + B\cos x + C\sin x$

Choosing Between the Two Methods

Both methods find $y_p$. Use the table below to decide which to apply.

✦ Undetermined Coefficients

  • Constant coefficients only
  • $r(x)$ is polynomial, exponential, sine/cosine, or products thereof
  • Faster — algebraic coefficient matching
  • Fails for $r(x) = \tan x$, $\ln x$, $1/x$, etc.
  • Fails for variable-coefficient ODEs

✦ Variation of Parameters

  • Works for any $r(x)$, including $\sec x$, $\ln x$, $1/x$
  • Works for variable-coefficient ODEs
  • No guessing required
  • Requires computing $y_h$ basis first
  • Integration may be difficult or impossible in closed form

Variation of Parameters — Formula

Given $y'' + p(x)y' + q(x)y = r(x)$ with homogeneous basis $\{y_1, y_2\}$:

$$y_p = -y_1 \int \frac{y_2\, r}{W}\,dx \;+\; y_2 \int \frac{y_1\, r}{W}\,dx$$
1
Compute the Wronskian:
$W(y_1, y_2) = y_1 y_2' - y_1' y_2$
2
Set up the integrals:
$u' = -\dfrac{y_2\, r}{W}$, $\quad v' = \dfrac{y_1\, r}{W}$
3
Integrate for $u$ and $v$:
$u = \displaystyle\int u'\,dx$, $\quad v = \displaystyle\int v'\,dx$  (no constants of integration needed)
4
Assemble the particular solution:
$y_p = u(x)\,y_1(x) + v(x)\,y_2(x)$
